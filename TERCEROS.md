KairoOS usa o descarga estos programas y recursos. Cada uno mantiene su propia licencia.

| Componente | Para qué lo usa KairoOS | Licencia / origen |
|---|---|---|
| **Microsoft Windows 11** | El sistema en sí, desde la ISO oficial de cada usuario | Licencia de Microsoft (no se distribuye) |
| **Windows ADK – Deployment Tools** (oscdimg) | Crear la ISO; lo instala KairoOS Creator desde Microsoft | Licencia de Microsoft |
| **[Chris Titus Tech WinUtil](https://github.com/ChrisTitusTech/winutil)** | Ajustes recomendados durante la instalación y acceso directo | MIT |
| **[HackBGRT](https://github.com/Metabolix/HackBGRT)** | Logo de arranque de KairoOS (incluye el *shim* firmado para Secure Boot) | MIT |
| **[Windhawk](https://windhawk.net/)** y sus mods | Estilo de la barra de tareas y del menú Inicio | GPL-3.0 (se descarga con winget) |
| **[Montserrat](https://fonts.google.com/specimen/Montserrat)** | Tipografía de las pantallas de KairoOS | SIL Open Font License 1.1 |
| **Steam, Epic Games Launcher, Discord** | Launchers de juegos (se descargan con winget de sus fuentes oficiales) | De sus respectivos autores |
| **Microsoft Visual C++, DirectX, .NET** | Librerías para juegos (se descargan de Microsoft) | Licencia de Microsoft |
| **[Ninite](https://ninite.com/)** | Acceso directo para instalar programas | Servicio de Secure By Design Inc. |

Windows, DirectX, .NET y Visual C++ son marcas de Microsoft Corporation. Steam es marca de Valve, Epic Games de Epic Games Inc. y Discord de Discord Inc. KairoOS no está afiliado con ninguna de ellas.
